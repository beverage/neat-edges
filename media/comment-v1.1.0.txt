v1.1.0 update:

Three new styles of floor border: an inlay, a carved vine, and pebbles set in grout, built from stone, for paths outdoors.

Every style now has a diagonal piece, for diagonal walls such as Diagonal Walls 2's.

The Floors tab has one button per shape, holding every style: left-click builds the style shown, right-click lists the others.

Borders are now drawn from one strip per style, so every border of one style in a map section draws in a single call, whatever its materials and paint.

Mod authors can draw their own trims the same way, diagonals and patterns included. The README on GitHub has the details.

Borders you have already built load as they are and harden the same edges.
